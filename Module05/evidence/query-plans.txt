SCAN means SQLite reads an input broadly. SEARCH means it performs targeted
lookups, usually through a key or index. The normalized query scans job_part and
looks up the related job, machine, and part rows. The indexed report plan walks
the complete machine index and then fetches table data. The unindexed plan uses
one table scan. Every design still needs temporary B-trees for grouping and
ordering because the available indexes do not fully provide that order.
